# Обновление KYC · 25 октября 2026

## Что изменено

- Старт, каталог и инструкции говорят о помощи с KYC — проверкой личности своего аккаунта. Пользователь проходит проверку сам в официальном сервисе.
- Короткое и полное описания сокращены и не содержат цен. Стоимость сопровождения и условия показываются перед созданием заявки: Claude · Армения $35, Европа $50; Alipay — по согласованию.
- Новая заявка сразу предлагает написать вопрос в чат. Для обычного сообщения не требуется дополнительная кнопка.
- В демо-оплате сохранены явное обозначение ДЕМО, отсутствие переводов и реквизитов. Убрана лишняя фраза о ещё не рассчитанной сумме в USDT. Цена показана как стоимость сопровождения в USD.
- После выбора демо-сети основное действие — «К заявке», дополнительное — «Выбрать другую сеть». Выбор сети не меняет цену, статус или версию заявки.

Сохранены переключение ролей, цены, все 37 демонстрационных сетей, callback-переходы, пометки ChatGPT/Gemini как примеров услуг. Документы, селфи, пароли и коды входа бот не принимает для передачи оператору.

## Проверка приложения

- **141 тест прошёл**: полный автоматический путь одного администратора через клиентскую заявку, обычное сообщение, демо-сеть, возврат в админку, ответ и закрытие; права доступа, сохранение режима и существующие сценарии.
- Проверка текста демо-оплаты обновлена под новую короткую формулировку. Проверки отсутствия адресов, платёжных кнопок, invoice-вызовов и изменения состояния заявки сохранены.
- **Ruff: замечаний нет.**

Тесты используют имитацию Telegram API и изолированную базу. Результаты живой проверки и публикации приведены ниже; автоматические тесты не выдаются за физические клики.

## Проверка рабочего бота

Полный путь выполнен через настоящие обработчики с искусственно созданными входящими действиями и реальными ответами Telegram. Это не физический клик каждой кнопки. Использовались рабочая база и только Telegram-профиль владельца.

- Создана тестовая заявка №0001: Claude · Армения, $35.
- Сохранены два сообщения клиента с явной пометкой ТЕСТ и один тестовый ответ оператора. Telegram подтвердил доставку ответа; ответ открыт в клиентской истории.
- Демо-сеть TON сохранилась. Цена, статус и версия заявки после выбора сети не изменились; реквизитов, счёта и перевода денег нет.
- Через переключатель выполнены переходы клиент → администратор → клиент → администратор.
- Заявка завершена, итоговый режим — администратор. История сохранена для просмотра в админке.
- Telegram принял 10 новых сообщений и 19 обновлений экранов.
- В установленном Telegram визуально подтверждены новый аватар, карточки клиента/администратора, текст тестового обращения и выбранная демо-сеть.

## Оформление

Новые логотип и баннер созданы встроенным Imagegen в едином стиле: чёрный фон, ледяное свечение, зернистость, собственный знак сканирования и проверки. Аватар опубликован через Telegram Bot API. Баннер 640×360 установлен через официальный BotFather Mini App внутри Telegram macOS: Edit Info → Set Welcome Picture → Update. Сохранение подтверждено повторным открытием настроек и скриншотом `assets/telegram-brand-published.png`.

Текст под баннером сокращён до трёх коротких строк, без цен. Русское описание и описание по умолчанию опубликованы и проверены чтением API. Промпты и файлы — `assets/README.md`.

Рабочий бот перезапущен как прежний локальный сервис macOS. Веб-вход не выполнялся: пользователь предпочёл приложение. Управление обычными inline-кнопками в этом приложении по-прежнему недоступно инструменту; управление формой BotFather доступно и выполнено.
