# Премиум-эмодзи Telegram

## Клиентские кнопки

На главной, в каталоге и карточке услуги бот запрашивает иконки из [TgAndroidIcons](https://t.me/addemoji/TgAndroidIcons). 21 ноября 2026 года через `getCustomEmojiStickers` сверены ID, альтернативные эмодзи и признак `needs_repainting`. Изображения проверены по миниатюрам Telegram. Клиент может окрашивать их в цвет текста кнопки.

Каталог обозначен слоями, заказы — списком, помощь — наушниками. В каталоге предусмотрены значки графика, магазина, кошелька, Telegram, игральных костей и глобуса. Галочка обозначает оформление, значок ответа — переход к уже открытой переписке. Ссылки возврата сохраняют короткую подпись со стрелкой.

Сопоставления хранятся в `verifydesk/theme.py::NAV_ICONS`. В обычной клавиатуре бот задаёт `icon_custom_emoji_id`. В скруглённой кнопке он передаёт иконку внутри текста вместе с альтернативным эмодзи из метаданных Telegram. Сервер может вернуть альтернативный символ. При явном отказе из-за иконки бот повторяет операцию с текстовыми кнопками и запоминает этот режим. [Формат кнопки](https://core.telegram.org/bots/api#richmessagebutton) · [Ограничения для ботов](https://core.telegram.org/bots/api#inlinekeyboardbutton).

При проверке @everykyc_bot 21 ноября 2026 года Telegram принял разметку главной и вернул обычные символы для каталога, заказов и помощи. При передаче иконки как объекта `RichTextCustomEmoji` результат был таким же. В обычной клавиатуре Telegram опустил запрошенный ID. Поэтому в этом чате на скруглённых кнопках сейчас видны альтернативные эмодзи. Бот продолжает запрашивать оригиналы при обычной отправке экранов.

## Иконки бирж из GentleeChron

Проверено 6 ноября 2026 года. Источник: [CryptoPack | @GentleChron](https://t.me/addemoji/GentleeChron).

Через `getStickerSet("GentleeChron")` получены 200 элементов типа `custom_emoji`. Ниже указаны только логотипы, сопоставленные с изображениями из набора вручную. Позиция нужна для повторной проверки, в приложении используются стабильные `custom_emoji_id`, а не порядковые номера. ## Включение

По умолчанию логотипы бирж выключены. По команде `/style` в режиме оператора бот проверяет известные ID в наборе и отправляет одно сообщение с образцами кнопок. В `data/theme.json` сохраняются только логотипы, которые Telegram вернул в `reply_markup` отправленного сообщения. После успешной проверки бот снова запрашивает также иконки навигации.

Если Telegram отклоняет оформление, обычные подписи остаются рабочими. При неопределённом сетевом результате тестовое сообщение автоматически не повторяется. Секретов в таблице нет: `custom_emoji_id` — публичные идентификаторы изображений.

Согласно [официальному Telegram Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton), для `icon_custom_emoji_id` боту требуется дополнительное имя, купленное на Fragment, либо Premium у его владельца при прямой отправке сообщения ботом в чат. Клиенту отдельная подписка не требуется по этому условию. Проверка отображения на конкретных версиях Telegram остаётся отдельной проверкой.

## Проверка логотипов бирж 6 ноября 2026 года

Реально выполнены только чтение набора и просмотр его публичных изображений. Сообщение `/style` в рабочий чат не отправлялось; включение и внешний вид иконок в живом Telegram пока не подтверждены. Автоматические тесты проверяют отсутствие включения без возвращённых иконок, частичное подтверждение, сохранение настройки, недопустимую подмену бренда, отказ API и отсутствие повторной отправки при тайм-ауте.
