# Иконки бирж из GentleeChron

Проверено 6 ноября 2026 года. Источник: [CryptoPack | @GentleChron](https://t.me/addemoji/GentleeChron).

Через `getStickerSet("GentleeChron")` получены 200 элементов типа `custom_emoji`. Ниже указаны только логотипы, сопоставленные с изображениями из набора вручную. Позиция нужна для повторной проверки, в приложении используются стабильные `custom_emoji_id`, а не порядковые номера. Значение обычного `emoji` у набора — произвольный смайлик, оно не определяет биржу.

Соответствия находятся в `verifydesk/theme.py::EXCHANGE_ICONS`. Для остальных сервисов сохраняется текстовое название без чужого логотипа. На кнопке иконка дополняет название и цену.

## Включение

По умолчанию иконки выключены. Оператор вызывает `/style` в режиме оператора: бот проверяет наличие известных ID в наборе и отправляет оператору одно сообщение с образцами кнопок. В `data/theme.json` сохраняются только те иконки, которые Telegram вернул в `reply_markup` отправленного сообщения. Успешное чтение набора само по себе ничего не включает. Предыдущая настройка с общими иконками Telegram также не включает логотипы бирж.

Если Telegram отклоняет оформление, обычные подписи остаются рабочими. При неопределённом сетевом результате тестовое сообщение автоматически не повторяется. Секретов в таблице нет: `custom_emoji_id` — публичные идентификаторы изображений.

Согласно [официальному Telegram Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton), для `icon_custom_emoji_id` боту требуется дополнительное имя, купленное на Fragment, либо Premium у его владельца при прямой отправке сообщения ботом в чат. Клиенту отдельная подписка не требуется по этому условию. Проверка отображения на конкретных версиях Telegram остаётся отдельной проверкой.

## Проверка этой версии

Реально выполнены только чтение набора и просмотр его публичных изображений. Сообщение `/style` в рабочий чат не отправлялось; включение и внешний вид иконок в живом Telegram пока не подтверждены. Автоматические тесты проверяют отсутствие включения без возвращённых иконок, частичное подтверждение, сохранение настройки, недопустимую подмену бренда, отказ API и отсутствие повторной отправки при тайм-ауте.
