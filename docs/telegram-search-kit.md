# EVERYKYC: имя, описания и ссылки

Обновлено **6 ноября 2026, Asia/Amman**. Материалы для переработки [@everykyc_bot](https://t.me/everykyc_bot). Посты ниже — черновики: из этой задачи они не публиковались и не рассылались. Имя и оба описания применены для русского языка и версии по умолчанию; значения проверены повторным чтением Telegram API.

## Публичная карточка

**Имя:** EVERYKYC · KYC и верификация

**Username:** @everykyc_bot

**Короткое описание:**

Помощь с KYC и верификацией: Claude, Bybit, Alipay и другие сервисы. Заказ и оператор — в одном чате.

**Полное описание:**

Помощь с KYC и верификацией вашего аккаунта.

Claude, Bybit, Alipay и другие сервисы — выберите в каталоге. Цена, заказ и переписка с оператором здесь.

Проверку вы проходите самостоятельно на свои данные. Географию и условия уточнит оператор. Решение принимает платформа.

Независимый сервис сопровождения. Нажмите «Начать».

Источник полей для синхронизации — `verifydesk/catalog.py`. Бренд соответствует существующему username; KYC и «верификация» объясняют задачу. Улучшение позиции не гарантируется. Обоснование и первоисточники — в [исследовании поиска](telegram-search-audit.md).

## Баннер

Основной текст: **EVERYKYC**. Короткая подпись: **Помощь с верификацией**. Баннер подготовлен, его загрузка через BotFather пока не выполнена.

Визуальное направление по запросу владельца: человек с неразличимым лицом, тема проверки личности, знаки Claude, Bybit и Binance. Они не должны выглядеть как подтверждение официального партнёрства. Binance на баннере — визуальный элемент по запросу, а не новая доступная услуга. Цены, наличие услуг и шаги заказа остаются обычным текстом бота.
