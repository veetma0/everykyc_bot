# EVERYKYC · интерфейс и оформление

Обновлено 6 ноября 2026, Asia/Amman. Эта редакция заменяет предыдущую переработку «Эврикус».

## Новая версия

- Главная: один главный вход в каталог, быстрые кнопки Claude, Bybit и Alipay с актуальными ценами; инструкция, заказы, помощь и правила. Быстрый выбор открывает карточку, а не создаёт заказ.
- При активном заказе — сервис, цена, состояние и одно главное действие «Продолжить заказ». Каталог и история остаются рядом.
- Шесть категорий и услуги в две колонки, по восемь услуг на странице. Короткое название «AI и сервисы» помещается на ширине 320 px. Возврат из карточки сохраняет страницу каталога.
- Карточка услуги начинается с названия и цены. Условия, собственный аккаунт, самостоятельная проверка, отсутствие списаний при создании и отдельная подписка Claude указаны до оформления.
- Карточки заказа, помощи, профиля и кабинета оператора сокращены. На первом плане статус и следующий шаг; ответы по-прежнему отправляются обычным текстом в выбранную переписку.
- Настоящие стили Telegram: `primary` для главного следующего действия, `success` для подтверждения оплаты и завершения, `danger` для окончательного подтверждения отмены. Вторичные кнопки нейтральные. Палитра определяется Telegram.
- Проверенные custom emoji бирж и текстовый fallback сохранены. Удаление неподдерживаемой иконки не удаляет нативный стиль кнопки.

Цены, доступность услуг, правила согласия, история, оплата, привязка Telegram Reply и права доступа не менялись. Новых оптовых переписок по-прежнему нет. Binance не добавлен в каталог.

## Бренд и материалы

Имя: **EVERYKYC · KYC и верификация**. Username: **@everykyc_bot**. Источник метаданных — `verifydesk/catalog.py`. Старое точное значение `BOT_TITLE=Эврикус` при запуске мигрирует на EVERYKYC; произвольные пользовательские названия сохраняются.

Короткое описание: «Помощь с KYC и верификацией: Claude, Bybit, Alipay и другие сервисы. Заказ и оператор — в одном чате.»

Баннер: графит, тёплый белый, акцент сканирующей рамки; человек со спины без видимого лица; Claude, Bybit и Binance как визуальные элементы запроса. Аватар — самостоятельная компактная монограмма в той же палитре. Партнёрство с платформами не заявляется.

- `assets/everykyc-banner.png` — исходный баннер.
- `assets/everykyc-welcome-640x360.png` — экспорт для BotFather.
- `assets/everykyc-avatar.png` и `.jpg` — аватар.
- `assets/everykyc-banner-prompt.md` и `everykyc-avatar-prompt.md` — точные промпты встроенного Imagegen.

## Исследование

Выбор нативных компонентов опирается на официальные обновления Telegram: [цветные кнопки и дизайн](https://telegram.org/blog/crafting-android-design-and-more), [стили кнопок](https://core.telegram.org/api/bots/buttons#button-styles), [inline-навигация](https://core.telegram.org/bots/features#inline-keyboards). Эти источники подтверждают возможности, но не измеренный рост конверсии.

Название содержит бренд, KYC и «верификация». Обещаний первого места нет; фактические позиции этой задачей не измерялись. Подробнее — [исследование поиска](telegram-search-audit.md) и [комплект текстов](telegram-search-kit.md).

## Проверки

610 тестов прошли. Ruff и `git diff --check` без ошибок. Тесты используют отдельные базы и имитацию API; клиентам не отправлялись тестовые сообщения, реальные платежи не выполнялись. Дополнительно проверено, что быстрый выбор показывает правильную цену и услугу, не создавая заказа и уведомления оператору.

[Интерактивный макет](../artifacts/ui-preview.html) собран из настоящих функций экранов. Проверены главная, карточка Claude, создание демонстрационного заказа и профиль с баннером, светлая и тёмная темы, ширины 320/390. При просмотре найдено и исправлено обрезание названия категории. Макет содержит вымышленные данные и не является живым Telegram; вид на физическом телефоне не проверен.

Генерация макета: `.venv/bin/python scripts/render_ui_preview.py`.

## Состояние публикации

- **Профиль опубликован:** имя и оба описания для русского языка и версии по умолчанию проверены повторным чтением Telegram API. Новый аватар принят, идентификатор фотографии изменился.
- **Баннер подготовлен:** загрузка description picture через BotFather не выполнена. Управление приложением Telegram дважды завершилось таймаутом; старый баннер не считается заменённым.
- **Рабочий интерфейс:** публикация изменений кода отслеживается отдельно; локальная проверка не доказывает состояние Railway.
- Telegram API отвечает, webhook отсутствует, при проверке очередь входящих обновлений была пустой. Это не подтверждает весь живой диалог.
- Railway CLI не авторизован. Локальный polling не запускался, чтобы не создавать конфликт с облачным экземпляром.

Оставшаяся внешняя операция: установить `everykyc-welcome-640x360.png` через BotFather → Edit Description Picture и повторно открыть настройки для проверки. Живой проход `/start` → каталог → услуга → возврат и журналы Railway требуют отдельной проверки.
